# Vendo — marketing website

Next.js (App Router) + TypeScript, exported as a fully static site.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # static site -> ./out (upload anywhere: Vercel, Netlify, S3, cPanel)
npm run illustrations  # regenerate public/illustrations/*.svg (Python 3, stdlib only)
```

Set `NEXT_PUBLIC_SITE_URL` (e.g. `https://vendo.ng`) at build time so social previews use absolute URLs.

## Where things live

- **Company details** (phones, email, WhatsApp, address, socials, cities): `lib/site.ts` — edit once, used everywhere.
- **Design tokens + all styles**: `app/globals.css` (brand blue `#0064FF`, Outfit + Caveat fonts).
- **Brand assets**: `public/brand/` — transparent logos/icons extracted from the original JPGs, app icon, WhatsApp QR (cropped from the flyer).
- **Illustrations**: `public/illustrations/` — isometric SVGs generated by `scripts/illustrations.py`. Change colours or layout there and re-run; don't hand-edit the SVGs.

## Dark mode

- Colours are CSS tokens in `app/globals.css`: light values in `:root`, dark values in `:root[data-theme="dark"]`. Use the tokens (`--surface`, `--heading`, `--muted`, …) instead of hex values in new styles.
- An inline script in `app/layout.tsx` sets `data-theme` before first paint (saved choice, otherwise the OS setting). `components/ThemeToggle.tsx` switches it and saves it as `vendo-theme` in localStorage.
- Every illustration has a night version (`x-dark.svg`, generated by the same script). Use `<Art src="/illustrations/x.svg" />` and the right one shows automatically.

## Motion

- Illustrations animate inside the SVGs themselves (parcels on the belt, road markings, the tracking route, pulsing lights). Defined in `scripts/illustrations.py` (`ANIM_CSS` and `Scene.keyframes`).
- Page motion lives at the end of `app/globals.css`: hero entrance, floating phone/cards, and the scroll reveal driven by `components/ScrollReveal.tsx`.
- Everything is disabled for visitors with "reduce motion" turned on (in the page and inside the SVGs).

## No backend (yet)

Booking bar, contact form and join form open **WhatsApp** (or email) with the details pre-filled. When the API exists, swap the `submit` handlers in `components/BookingBar.tsx`, `ContactForm.tsx` and `JoinForm.tsx`.

## Before launch

- Legal pages are drafts: get them reviewed, then set `LEGAL_DRAFT = false` in `lib/site.ts`.
- Verify social URLs in `lib/site.ts`.
- Replace the "coming soon" store badges in `components/StoreBadges.tsx` with the official badges + store links once the apps are live.
